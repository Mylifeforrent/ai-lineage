# 02 · 血缘画布工作区

> 定位：Clew 的主工作台。登录后即进入，承担「选数据集 → 看血缘图 → 核对字段与边」的核心闭环：顶栏全局搜索与跳数、左侧数据集栏、中央 React Flow 画布（节点/边/组/浮层）、右侧详情栏（内容规格见 03 文档）。本页是 Data-Dense Dashboard 气质（00 §1.1）的主战场：白卡片 + 细边框分层 + 克制品牌橙，信息密度高而噪音低。（2026-10 Clew 品牌改版：blue→brand、追踪红→橙、manual 琥珀→teal，见 00 文首注记。）
>
> 依据与来源：
> - `docs/04_hifi/00_设计总览与DesignToken.md`（token 唯一来源，引用格式「00 §x.x」；画布专用规格见 00 §2.5、§2.4）
> - `docs/02_prototype/lineagelite-lofi-prototype.html` 血缘画布屏（信息架构基线：顶栏/侧栏/画布/详情栏四区、图例、AI 建议边）
> - `docs/03_dev/02_前端开发文档.md` §六组件清单、§七画布实现（getEdgeVisual 四形态、handle 体系、折叠/分组、跳数契约）
> - 组件源码：`Workspace.tsx`、`TopBar.tsx`、`DatasetSidebar.tsx`、`LineageCanvas.tsx`、`DatasetNode.tsx`、`GroupNode.tsx`、`LineageEdge.tsx`、`Brand.tsx`、`SourceBadge.tsx`、`lib/layout.ts`、`src/index.css`
>
> 范围约束：只改视觉与布局，不改任何功能逻辑（布局算法、handle 约定、边构建规则、快捷键全部保留）；不新增依赖。右栏 `DetailPanel` / `EdgeDetailPanel` 的**内容**与两个模态归 03 文档；本页负责 Workspace 三栏骨架与右栏容器位置。`SourceBadge` 规格在本页定稿（03 引用）。

## 一、页面定位与入口

| 项 | 说明 |
|---|---|
| 进入时机 | 登录成功后 `App` 渲染（`key={token}`）；本页即产品唯一主视图，无路由 |
| 对应组件 | `Workspace.tsx`（容器）组装：`TopBar`、`DatasetSidebar`、`LineageCanvas`（内含 `DatasetNode` / `GroupNode` / `LineageEdge`）、`DetailPanel` / `EdgeDetailPanel`（03 文档） |
| 页面状态 | 由 `Workspace` 持有：种子数据集、跳数（1–5，默认 3）、AI 覆盖子图、画布过滤（置信度 / 隐藏 AI 边 / 仅确认）、折叠与分组、字段/边选中、各抽屉与模态开关 |
| 数据链路 | `getSubgraph`（种子 + hops + direction:'both'）→ `applyGraph` 统一入口；AI 出图经 `onGraph` 覆盖（dev 文档 §7.6） |

## 八、无障碍要点（本页特有）

1. **画布键盘可达**：`nodesFocusable` 保留，节点 focus outline（2px `brand-600/65` + offset 3px）不被裁切（00 §10.3）；边 `focusable={false}` 为既有取舍（边操作经 tooltip/详情面板），保持登记。
2. **色彩不做唯一编码**：血缘来源 = 颜色 + 线型（实/虚/流动）+ 徽章文字三重编码（00 §10.6）；AI 徽标有 tooltip 文字兜底。
3. **热区**：跳数按钮 ≥25×24、图标按钮（历史/关闭/折叠等）≥24×24、搜索清空 24×24、handle 为画布特例（拖拽交互，已有 18px 边命中区补偿）。
4. **`/` 快捷键**与 kbd 可视提示保留；快捷键不劫持输入态（现逻辑）。
5. **图例双编码**：侧栏图例 = 线样（实/虚）+ 颜色 + 文字标签，色弱用户可辨「字段级 vs 表级 vs AI」。
6. **`aria-current`**（侧栏选中项）、`aria-pressed`（跳数）、`aria-expanded`（AI 按钮/菜单/字段展开）、边 `ariaLabel`（四端点描述）全部保留，不因改版丢失。
7. **MiniMap/Controls**：`ariaLabel` 保留；MiniMap 在 md 以下隐藏（触屏场景非主操作路径）。
8. **加载/错误覆盖层**：`role="status"` / `role="alert"` + `aria-live` 保留，不被视觉改版破坏。
