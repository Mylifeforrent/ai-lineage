## 三、逐区域视觉规格

### 3.1 VersionDrawer

**头部**：`flex h-12 shrink-0 items-center justify-between gap-3 border-b border-line-soft px-4`——左：图标块 `flex h-8 w-8 items-center justify-center rounded-lg border border-blue-200 bg-blue-50 text-blue-700`（tag 16px）+ `text-[14px] font-semibold text-ink`「版本」；右：刷新 / 关闭 ghost 图标按钮（`h-8 w-8 rounded-lg text-ink-faint hover:bg-subtle hover:text-ink-soft` + 统一 ring，规格同 04 §3.1）。原头部说明文字移入滚动体首条。

**说明条（滚动体首条）**：`flex items-start gap-2 rounded-lg border border-line bg-card px-3 py-2.5 text-[12px] leading-5 text-ink-muted`（info 图标 12px `text-ink-faint`）「回滚只反做变更日志；标注为追加式，不受回滚影响。」——中性信息条，不用 info 蓝底（非操作警示，控制蓝色面积）。

**回滚成功 notice（条件）**：`flex items-start gap-2 rounded-lg border border-success/25 bg-success-soft px-3 py-2.5 text-[12px] leading-4 text-success-deep`（check 12px + `rollbackNotice` 现有文案）。

**分区标题行**：`mb-2 flex items-center justify-between`——h3 `flex items-center gap-1.5 font-mono text-[11px] uppercase tracking-[0.16em] text-ink-faint`（layers/tag/diff 图标 11px）+ 右侧计数 `font-mono text-[11px] tabular-nums text-ink-faint`。

**⓪ 导入批次行**（容器 `divide-y divide-line-soft overflow-hidden rounded-xl border border-line bg-card`，行 `flex flex-wrap items-center gap-x-2.5 gap-y-1 px-3 py-2.5`）：

| 元素 | 规格 |
|---|---|
| 版本号 | `font-mono text-[13px] font-semibold tabular-nums text-ink`「v{version_no}」 |
| 格式 chip | `rounded border border-line bg-page px-1.5 py-px font-mono text-[11px] uppercase text-ink-faint`（00 §7.5） |
| 文件名 | `min-w-0 flex-1 truncate font-mono text-[11px] text-ink-faint`（`title` 全量保留，空值「—」） |
| 时间 · 操作者 | `shrink-0 font-mono text-[11px] text-ink-faint` |
| 状态徽章 | 有效：`rounded-full border border-transparent bg-success-soft px-1.5 py-px font-mono text-[11px] text-success-deep`；已回滚：`border-line bg-subtle text-ink-muted`（见文末待补充 #2） |

**ⓟ 业务标签行**（容器同上，行 `px-3 py-2.5`）：

- 主行 `flex flex-wrap items-center gap-x-2 gap-y-1`：标签名 `font-mono text-[13px] font-semibold text-blue-800`；锚点 chip `rounded border border-line bg-page px-1.5 py-px font-mono text-[11px] tabular-nums text-ink-faint`「变更序号 #120」；时间 · 操作者 `font-mono text-[11px] text-ink-faint`；**回滚按钮**（canRollback，`ml-auto`）：danger ghost sm——`inline-flex h-7 items-center gap-1 rounded-md border border-danger/25 bg-danger-soft px-2 text-[11px] font-medium text-danger-deep transition-colors duration-150 hover:border-danger/45` + 统一 ring（rollback 11px「回滚到此标签」）。
- 说明（可选）：`mt-1 break-words text-[12px] leading-4 text-ink-muted`。
- 空态：`rounded-xl border border-dashed border-line px-3 py-4 text-center text-[12px] text-ink-muted`「还没有业务标签。标签会锚定当前变更序号，供版本差异与回滚使用。」（现有文案）。

**打标签表单（canWrite）**：外卡 `mt-2.5 rounded-xl border border-line bg-card p-3`；行 `flex flex-wrap items-center gap-2`——标签名 `input.field-input h-8 w-[150px] font-mono text-[12px]`（`sr-only` label「版本标签名」+ placeholder 现有）、说明 `input.field-input h-8 min-w-[160px] flex-1 text-[13px]`（sr-only label）、提交 primary `h-8 px-2.5 text-[12px]`（plus 11px；busy「创建中…」+ spinner 白底小号；空名 disabled 中性化）；辅注 `mt-1.5 font-mono text-[11px] text-ink-faint`「编辑及以上角色可创建；重名会返回 409。」；错误 `mt-1.5 rounded-md border border-danger/25 bg-danger-soft px-2 py-1.5 text-[11px] leading-4 text-danger-deep` `role="alert"`。viewer 分支：`mt-2 flex items-center gap-1.5 text-[11px] text-ink-faint`（lock 11px + 现文案）。

**ⓓ 标签间差异**：

- 前置（tags < 2）：dashed 空态「至少创建两个标签后，才能对比标签之间的净变更。」（规格同标签空态）。
- 控制行：外卡 `rounded-xl border border-line bg-card p-3`；`flex flex-wrap items-end gap-2`——两个 label（00 §7.2：`mb-1.5 block text-[12px] font-medium text-ink-soft`「起始标签 / 结束标签」）+ 原生 select（00 §7.3：`.field-input h-8 min-w-[130px] font-mono text-[12px] pr-8` + chevron 14px）；中间箭头 `pb-2 text-ink-faint`（arrow-right 12px，`aria-hidden`）；计算按钮 secondary `h-8 px-3 text-[12px]`（diff 11px；busy「计算中…」+ spinner + `cursor-wait`）。
- 错误条：danger 组合 `text-[11px] leading-4`，`role="alert"`。
- 结果块 `mt-3 border-t border-line-soft pt-3`：摘要行 `flex flex-wrap items-center gap-1.5`——区间 `font-mono text-[12px] font-medium text-ink-soft`「{from} → {to}」+ 三枚计数 pill（`rounded-full border border-transparent px-2 py-px font-mono text-[11px] tabular-nums`）：
  - `+N 新增` → `bg-success-soft text-success-deep`；`~N 修改` → `bg-warning-soft text-warning-deep`；`−N 删除` → `bg-danger-soft text-danger-deep`。
- **变更清单（单栏）**：`mt-2 max-h-[240px] overflow-y-auto divide-y divide-line-soft overflow-hidden rounded-lg border border-line-soft`，行 `flex items-start gap-2 bg-card px-2.5 py-1.5`——op 徽章（同上三色组，`rounded border border-transparent px-1.5 py-px font-mono text-[11px]`「新增/修改/删除」）、实体类型 `shrink-0 text-[11px] text-ink-faint`（数据集/字段/血缘边）、实体键 `min-w-0 break-all font-mono text-[12px] text-ink-soft`。480px 宽度下单栏清单足够（双栏需 ≥720px，不采用）。
- diff 为空：`mt-2 text-[12px] text-ink-muted`「两个标签之间没有净变更。」
- 脚注：`mt-2 flex items-center gap-1 text-[11px] text-ink-faint`（info 10px）「差异按实体自然键归并，统计净变化；标注不参与差异统计。」（现有文案）。

## 八、无障碍要点（本页特有）

1. **破坏性操作双通道**：回滚必须经 ConfirmDialog（`role="alertdialog"`）+ 文字说明「将反做…所有变更」；危险不只靠红色（图标 + 完整句子）。
2. **busy 锁定**：ConfirmDialog / UserModal submitting 中 Esc、遮罩点击、取消按钮全部禁用（现有行为逐条保留）；VersionDrawer pendingRollback 中 Esc 与遮罩不关抽屉（现有）。
3. **初始焦点**：模态与抽屉打开即聚焦关闭/取消按钮（现有）；关闭后焦点还原依赖触发按钮 DOM 顺序（现有，不额外处理）。
4. **表单标签**：打标签行内输入用 `sr-only` label（空间受限场景，00 §7.2 允许）；UserModal 表单全部改为可见 label + `htmlFor`（§七#19）。
5. **表格 / 列表语义**：批次、标签、用户、diff 清单均为语义列表（`div` 分区 + 计数由分区标题播报）；时间线用 `ol`（现有保留）。
6. **色彩不做唯一编码**：op = 颜色 + 文字徽章（新增/修改/删除）；批次状态 = 底色 + 文字（有效/已回滚）；时间线节点颜色仅作徽章冗余。
7. **对比度抽查点**：`success-deep` on `success-soft`（6.81）、`warning-deep` on `warning-soft`（4.84）、`danger-deep` on `danger-soft`（5.91）、`blue-800` on `card`（8.72）、`white` on `bg-danger`（4.83）——全部在 00 §2.6 表内。
8. **角色可辨**：角色徽章三套有文字（admin/editor/viewer），不依赖颜色差异（viewer 中性灰仍可读）。
