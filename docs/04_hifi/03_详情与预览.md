## 一、页面定位与入口

| 组件 | 形态 | 进入时机 | 退出时机 |
|---|---|---|---|
| `DetailPanel` | 常驻右栏（w-320，xl 以下为底部块状） | 默认显示（空态引导）；点击画布字段行 | 点击边 / 关闭按钮 / 切换种子清空选择 |

## 三、逐区域视觉规格

### 3.1 右栏共用骨架（两面板一致）

- 容器：`relative flex w-full shrink-0 flex-col border-t border-line bg-card xl:h-full xl:w-[320px] xl:border-l xl:border-t-0`（替换 `bg-[#f8f5ed]/70/80`、`xl:w-[340px]`、`relative z-10`——z 移除见 02 §二）。
- 头部（h-12，对齐 00 §7.7）：`flex h-12 shrink-0 items-center justify-between border-b border-line-soft px-4`。
  - 左：眉标 `font-mono text-[11px] uppercase tracking-[0.18em] text-ink-faint`（「字段检查」/「血缘边检查」）+ 面包屑行 `mt-1 flex min-w-0 items-center gap-1.5 font-mono text-[12px] text-ink-muted`（图标 12px + `dataset.id › field.name`，当前段 `text-blue-700`）。
  - 右：图标按钮组，规格统一：`flex h-7 w-7 items-center justify-center rounded-md text-ink-faint transition-colors duration-150 hover:border-line hover:bg-card hover:text-ink-soft` + 统一 focus ring（编辑按钮 hover `text-blue-700`）；`aria-label` / `title` 现有保留。

### 3.2 DetailPanel · 字段详情

**① 徽章行**：类型标签 `rounded border border-line bg-card px-1.5 py-0.5 font-mono text-[11px] uppercase text-ink-muted`；文件类型标签（`FileTypeBadge`）同规格 + file 图标 12px；来源徽章 = `SourceBadge`（02 §3.6 规格）。

**② 实体标题**：字段名 `break-all font-mono text-lg font-semibold text-ink`（18px 档「模态/抽屉标题」语义借用于面板实体标题；替换 22px `font-display`）；描述 `mt-1.5 text-[13px] leading-5 text-ink-muted`「暂无字段描述」兜底保留。

**③ 源文件卡**：`rounded-xl border border-line bg-card`；头行 `flex items-center gap-2 border-b border-line-soft px-3 py-2`（file 图标 12px `text-blue-600` + 眉标「源文件」`text-[11px] font-medium uppercase tracking-[0.12em] text-ink-faint`）；体：文件名 `truncate font-mono text-[13px] font-medium text-ink` + 「托管文件」徽章 `rounded border border-line bg-subtle px-1.5 py-px font-mono text-[11px] text-ink-muted`（中性信息徽章）；副行 `font-mono text-[11px] text-ink-faint`「源文件 #id」。

**④ 定位信封卡（本面板视觉锚点）**——人类可读定位 + 信封类型 + 复制按钮：

复制按钮三态文案：「复制定位」（default）/「已复制」（success 语义，图标换 check，1600ms 还原——现有时长保留）/「复制失败」（`text-danger-deep`，1800ms）。

**⑤ 操作行**：`mt-4 flex items-stretch gap-2`——「回源预览」primary（`h-9 flex-1 ... bg-blue-600`，图标 14px，删除现有品牌色投影）；「编辑」secondary `h-9 px-3`（canEdit 才渲染）。底部权限说明 `mt-2 flex items-center justify-center gap-1.5 text-[11px] text-ink-faint`（lock/edit 图标 12px + 现有两套文案保留）。

## 八、无障碍要点（本页特有）

1. **模态焦点圈定**：PreviewModal 的 Tab 圈定 + Esc + 关闭后焦点还原、EdgeCreateModal 的 Esc（submitting 锁定）与初始焦点——现有行为逐条保留，视觉改版不得破坏（00 §10.5）。
2. **复制反馈不只变色**：「已复制 / 复制失败」有文字变化（色弱可辨），复制成功另由按钮文案自述，无需 aria-live（瞬时状态，视觉 1.6s 足够）。
3. **表格双编码**：高亮列 = 底色 +「字段」文字徽章 + `sr-only caption`；XLSX 表头行 = warning 底 + 行号文字说明（title「表头行」保留）；合并单元格有文字「合并单元格」。
4. **表单标签**：全部 `htmlFor` 关联（现有保留）；label 从 8.5–10.5px 统一 12px 后可读性提升；标注输入 sr-only label 保留。
5. **错误条语义**：`role="alert"`（表单校验 / AI 失败 / 标注提交 / 下载失败）与 `role="status"` 区分保留。
6. **预览加载**：`aria-live="polite"` 容器包裹预览体（现有保留），骨架 `aria-hidden`。
7. **禁用态文案**：busy 按钮同时有 spinner + 文字（「确认中…」），不只靠透明度。
8. **键距**：面板滚动体 `pb-7` 底部留白，避免最后一条目贴边被 sticky 头遮挡焦点。
