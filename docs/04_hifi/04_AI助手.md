> 定位：工作台的「自然语言查血缘」层。右侧 480px 抽屉 `AiAssistantDrawer`，承载 LLM 状态检查、多轮对话、只读工具调用轨迹展示与出图联动画布（`onGraph` → `Workspace.applyGraph`，02 §一）。本页是 `ai` 色组（indigo，00 §2.4）在全站的第二主战场（第一是 AI 建议边）：AI 身份、模型徽章、工具轨迹强调一律走 `ai / ai-soft / ai-deep`，不与主蓝混用。
>
> 依据与来源：
> - `docs/04_hifi/00_设计总览与DesignToken.md`（token 唯一来源，引用格式「00 §x.x」；抽屉 §7.7、按钮 §7.1、输入 §7.2、徽章 §7.4、chip §7.5、空态 §7.9、加载 §7.10、层级 §6）

### 3.3 状态横幅（条件渲染，紧贴聚焦条下方）

容器：`shrink-0 border-b border-line-soft px-4 py-2.5`，内部提示条两种语义（soft 底一律 deep 正文，00 §2.3）：

| 分支 | 类组合 | 内容 |
|---|---|---|
| `statusError`（状态接口失败） | `flex items-start gap-2.5 rounded-lg border border-danger/25 bg-danger-soft px-3 py-2.5 text-[12px] leading-5 text-danger-deep`，`role="status"`，warning 图标 12px `text-danger` | 标题「无法读取 AI 状态」`font-medium` + 错误文案 + 重试按钮（见下） |
| 未配置（`!statusLoading && !status.configured`，含 503 回退） | 同上骨架，换 `border-warning/25 bg-warning-soft text-warning-deep`，warning 图标 12px `text-warning` | 标题「AI 助手暂不可用」+ `NOT_CONFIGURED_TEXT`（现有文案）+ 尾注「配置后点右上角刷新重新检测」 |

重试按钮（仅 statusError 分支）：danger ghost sm 变体 `inline-flex h-7 items-center gap-1 rounded-md border border-danger/25 bg-card px-2 font-mono text-[11px] text-danger-deep transition-colors duration-150 hover:border-danger/45` + 统一 ring（refresh 11px，「重试」）。

### 3.4 消息滚动体

容器：`min-h-0 flex-1 overflow-y-auto bg-page px-4 py-4 pb-6`，`role="log" aria-live="polite" aria-label="AI 对话消息"`（现有保留）。条目流 `space-y-3`，**不增加场动画**（对话以「即时出现」为反馈，追加动效会干扰阅读；00 §1.2 原则 5）。

**用户消息**（右对齐）：

```html
<div class="flex flex-col items-end">
  <div class="mb-1 font-mono text-[11px] uppercase tracking-[0.12em] text-ink-faint">你</div>
  <div class="max-w-[88%] whitespace-pre-wrap break-words rounded-xl rounded-tr-md border border-blue-100 bg-blue-50 px-3 py-2 text-[13px] leading-5 text-ink">
    {entry.content}
  </div>
</div>
```

（blue-50 底 + blue-100 描边表达「自己的消息」这一身份语义（00 §2.1 blue-100 场景）；正文用中性 `ink` 保证长问题可读性。`max-w-[88%]` 为本页一次性布局值。）

**AI 消息**（左对齐）：

- 名字行：`mb-1 flex items-center gap-1.5 font-mono text-[11px] uppercase tracking-[0.12em] text-ink-faint`，sparkles 10px `text-ai` + 「AI 助手」。
- 气泡：`rounded-xl rounded-tl-md border px-3 py-2.5`——正常 `border-line bg-card`；错误 `border-danger/25 bg-danger-soft/70`。
- 正文：`whitespace-pre-wrap break-words text-[13px] leading-6 text-ink-soft`；错误条目 `text-danger-deep`；模型无文字回答时兜底 `text-[12px] italic text-ink-faint`「模型未返回文字回答。」（现有文案）。

### 3.5 工具调用轨迹卡（折叠态 / 展开态）

替换现有 `ToolChips` 平铺 chips（8.5px + `title` 提示），升级为可折叠卡片。中文标签对齐 `TOOL_LABELS`（search_fields=搜索字段 / get_field_details=字段详情 / trace_lineage=追溯血缘 / get_field_history=变更历史；未知工具兜底「工具调用」，现有逻辑保留）。

**折叠态（默认）**——一行摘要：

```html
<div class="mb-2 overflow-hidden rounded-lg border border-line bg-page">
  <button type="button" aria-expanded={open} class="flex w-full items-center gap-2 px-2.5 py-2 text-left transition-colors duration-150 hover:bg-subtle/60 + 统一 ring">
    <Icon name="code" size={12} className="shrink-0 text-ink-faint" />

    <span class="flex min-w-0 flex-1 flex-wrap gap-1">
      <!-- 每个 chip：TOOL_LABELS 中文标签 + 成功/失败标记 -->
      <span class="inline-flex max-w-full items-center gap-1 rounded border border-line bg-card px-1.5 py-px font-mono text-[11px] text-ink-muted">
        <span className="shrink-0">{TOOL_LABELS[item.tool] ?? '工具调用'}</span>
        <span className={item.ok ? 'font-semibold text-success' : 'font-semibold text-danger'} aria-label={item.ok ? '调用成功' : '调用失败'}>{item.ok ? '✓' : '✗'}</span>
      </span>
    </span>
    <Icon name="chevron-down" size={12} className={`shrink-0 text-ink-faint transition-transform duration-150 ${open ? 'rotate-180' : ''}`} />
  </button>
</div>
```

**展开态**——header 下接明细列表（`border-t border-line-soft px-2.5 py-1.5 space-y-1.5`），每行：

- 行容器：`flex items-start gap-2 rounded-md px-1 py-1.5`；**失败行**整行加底 `bg-danger-soft`、标签 `text-danger-deep`（soft 底 + deep 正文，00 §2.3 规则）。
- 状态图标：check 12px `mt-0.5 shrink-0 text-success` / close 12px `text-danger`（替代现有 ✓/✗ 字符，色弱可辨）。
- 标签行：中文标签 `text-[12px] font-medium text-ink-soft` + 英文名 chip `rounded bg-subtle px-1.5 py-px font-mono text-[11px] text-ink-muted`。
- 参数全文：`mt-1 whitespace-pre-wrap break-all rounded-md bg-subtle px-2 py-1.5 font-mono text-[11px] leading-4 text-ink-muted`（完整 `JSON.stringify(item.args)`；替代折叠态的 64 字截断，subtle 底正文用 ink-muted，00 §2.2 硬规则）。

折叠/展开为纯 UI 状态（`aria-expanded`），不影响消息数据；默认折叠，含失败调用的消息默认展开。

## 八、无障碍要点（本页特有）

1. **对话语义**：消息区 `role="log" aria-live="polite"`（现有保留），新消息/错误/sending 态对屏幕阅读器可感知；横幅 `role="status"`。
2. **焦点管理**：打开即聚焦输入框（现有）；Esc 关闭（现有）；Tab 顺序：头部按钮 → 消息区（轨迹折叠钮）→ 输入区，无焦点陷阱；关闭后焦点还原交由 TopBar 触发按钮（现有 DOM 卸载行为，不额外处理）。
3. **图标按钮**：刷新 / 关闭 `aria-label` + `title`（现有保留）；轨迹 ✓/✗ 用 `aria-label`「调用成功/失败」（现有保留）。
4. **轨迹折叠**：`aria-expanded` 表达展开态；展开不是唯一信息通道（折叠态摘要已含全部工具与成败）。
5. **色彩不做唯一编码**：工具成败 = 颜色 + ✓/✗ 字符；AI 身份 = indigo 色 + sparkles 图标 + 文字「AI 助手」；suggest 卡未确认 = 虚线边框 + 文字说明。
6. **对比度抽查点**：`ai-deep` on `ai-soft`（8.88）、`success-deep` on `success-soft`（6.81）、`ink` on `blue-50`（≈16:1）、`ink-soft` on `card`（10.36）——全部在 00 §2.6 表内。
7. **禁用不只靠色**：发送 busy = spinner + 「发送中」文字；未配置 = placeholder 文案变化 + 横幅文字。
8. **reduced-motion**：滑入 / spinner 之外无持续动画；全部受全局规则关闭。
