# 01 · 登录页

> 定位：Clew 的入口屏。无有效会话（首次访问或 JWT 过期 401 登出）时由 `App` 渲染，登录成功后 `persistSession` 并进入 `Workspace`（02 文档）。它是用户对产品气质的第一印象，也是唯一允许出现大面积品牌深橙（`brand-900`）的页面——工作台内品牌橙退回交互语义（00 §1.2 原则 3）。
>
> 依据与来源：
> - `docs/04_hifi/00_设计总览与DesignToken.md`（本文全部 token 唯一来源，引用格式「00 §x.x」）
> - `docs/02_prototype/clew-lofi-prototype.html` 登录屏（居中卡基线——本页在其上按 00 决策定稿为左右分栏，见 §2）
> - `docs/03_dev/02_前端开发文档.md` §四认证（401 全局处理）与 §六组件清单（LoginPage 职责）
> - `prototype/frontend/src/components/LoginPage.tsx`、`Brand.tsx`（现状与改造依据）
>
> 范围约束：只改视觉与布局，不改登录逻辑（表单校验、AbortController、错误分支均保留现状）；不新增依赖、不新增组件。

## 一、页面定位与入口

| 项 | 说明 |
|---|---|
| 进入时机 | `App` 检测无会话时渲染；会话过期由 401 全局处理登出并携带 `notice`（「登录已过期」类提示）回到本页 |
| 对应组件 | `LoginPage.tsx`（含内部示意组件 `MiniNode`）、`Brand.tsx`（`BrandMark` / `Brand`） |
| 退出时机 | 登录成功回调 `onLoggedIn`，`App` 切换到 `Workspace`（`key={token}`） |
| 页面职责 | 品牌呈现（左栏）+ 认证表单（右栏）+ 会话过期提示（`notice`）+ 错误反馈 + 提交加载态 |

## 五、数据态

| 态 | 设计 |
|---|---|
| 初始 | 空表单；用户名 `autoFocus`（现有行为保留）；placeholder「请输入用户名 / 请输入密码」 |
| 客户端校验失败 | `error` 提示条（danger 组合，`role="alert"`），文案「请输入用户名和密码」；输入框保持用户已输入值 |
| notice（过期/登出） | 表单上方 warning 提示条（`role="status"`），与 error 不同时互斥（notice 为 props、error 为本地态，现有逻辑不变） |
| 提交中 | 按钮 disabled + spinner（`border-white/40 border-t-white` 小号）+ 文案「正在验证身份」；两个输入框同步 disabled |
| 服务端错误 | ApiError message 或「无法连接服务，请稍后重试」进 error 提示条；按钮恢复 default |
| 成功 | 无过渡动画，直接切换到 Workspace（现有行为，不设计额外转场） |

## 八、无障碍要点（本页特有）

1. **焦点起始**：`autoFocus` 用户名输入（保留）；Tab 顺序：用户名 → 密码 → 可见切换 → 提交按钮，无焦点陷阱。
2. **提示条语义**：notice `role="status"`、error `role="alert"`（现有保留），屏幕阅读器可区分「提示」与「错误」。
3. **错误不只靠色**：danger 提示条同时有 `warning` 图标 + 文字（00 §10.6）。
4. **对比度抽查点**（00 §2.6 表内组合）：`blue-100` on `blue-900`（深底正文）、`white` on `blue-600`（提交按钮）、`warning-deep` on `warning-soft`、`danger-deep` on `danger-soft`——前三项组合规则尚待回写 00（见下节），交付前用取色器验证 ≥4.5:1。
5. **密码切换**：`aria-pressed` 表达开关态（保留）；热区 28×28 ≥24×24。
6. **`autoComplete`**：`username` / `current-password`（保留），支持密码管理器。
7. **进场动画**：`fade-up` 300ms 受 `prefers-reduced-motion` 全局关闭（index.css 规则覆盖）。
